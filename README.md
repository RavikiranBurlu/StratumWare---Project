# StratumWare – SQL Data Warehouse & Analytics

Welcome to StratumWare! 🚀

StratumWare is an end-to-end SQL Server data warehouse project built to bring sales data from different sources into one structured and reliable system.

The project covers the complete data workflow — from loading and cleaning raw data to creating data models and generating business insights using SQL.

---

## 🏗️ Data Architecture

The project follows a Medallion Architecture with three layers:

### 🥉 Bronze Layer

Stores the raw data as it comes from the source files.
Data is loaded from CSV files into SQL Server without major changes.

### 🥈 Silver Layer

Cleans and prepares the raw data for further use.
This includes handling missing values, correcting data formats, removing duplicates, and standardizing the data.

### 🥇 Gold Layer

Contains clean, business-ready data.
The data is organized using a star schema with fact and dimension tables for reporting and analysis.

---

## 📖 Project Overview

The main goal of StratumWare is to build a simple and reliable data warehouse that can be used for sales analysis and reporting.

The project includes:

Data Architecture – Designing the warehouse using Bronze, Silver, and Gold layers.
ETL Process – Extracting data from source files, transforming it, and loading it into SQL Server.
Data Cleaning – Identifying and fixing data quality issues before analysis.
Data Modeling – Creating fact and dimension tables using a star schema.
SQL Analytics – Writing SQL queries to analyze customers, products, and sales.
Reporting – Creating business-focused insights from the warehouse data.

---

## 🎯 Project Objective

Build a SQL Server data warehouse that combines ERP and CRM sales data into a single, structured system.

The warehouse is designed to make the data easier to understand, query, and use for business analysis.

---

## 📊 Analytics & Insights

The final data model is used to analyze:

Customer Behavior – Understanding customer activity and purchasing patterns.
Product Performance – Identifying top-performing and underperforming products.
Sales Trends – Analyzing sales performance and trends over time.

These insights can help businesses better understand their customers, products, and overall sales performance.
